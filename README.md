## 💡 주요 기능  
- **대화 기억**  
  - MongoDB 및 OracleDB를 활용하여 사용자의 대화 내역 저장 및 활용  
- **욕설 및 비방 필터링**  
  - 부적절한 표현은 블러 처리 또는 경고 표시  
- **정보 제공**  
  - 요청 정보 제공 및 대체 방안 제안  
- **스케줄러 기능**  
  - 일정 추가, 알림, 우선순위 설정, 마감일 알림 및 작업 완료 처리  
- **문서 및 파일 관리**  
  - 사용자가 업로드한 파일 저장 및 관리  
- **정보 검색 기능**  
  - 다양한 데이터를 검색 및 제공  
- **음성 인식 기능**  
  - 음성 입력을 통한 대화 지원
